# Banco de preguntas

## Fundamentos

1. ¿Qué cambia en la confianza al pasar de una base firmada a una blockchain?
2. ¿Por qué una firma válida no demuestra que el firmante comprendió la interfaz?
3. ¿Qué información no aporta una prueba Merkle?
4. ¿Cómo afecta una partición a seguridad y vivacidad?
5. ¿Qué costo económico impide identidades Sybil en cada consenso?

## Bitcoin y EVM

1. Demuestra conservación de valor en una transacción UTXO.
2. ¿Por qué una wallet no “contiene” bitcoins?
3. Distingue nonce de cuenta y nonce de PoW.
4. ¿Cuándo conviene evento y cuándo storage?
5. ¿Por qué una llamada `view` desde otro contrato puede consumir gas?

## Desarrollo y seguridad

1. Escribe tres invariantes antes de implementar.
2. ¿Por qué CEI no resuelve toda reentrancia?
3. ¿Cómo se manipula un precio spot con liquidez temporal?
4. ¿Qué campos impiden repetir una firma en otra cadena?
5. ¿Qué riesgo añade un proxy aunque use una librería conocida?

## Producto y arquitectura

1. ¿Qué derecho real representa el token?
2. ¿Quién puede censurar, pausar, actualizar o retirar?
3. ¿Cómo sale un usuario si la gobernanza es capturada?
4. ¿Qué datos personales quedarían correlacionables?
5. ¿Cuál es el costo total frente a una alternativa sin blockchain?

Las respuestas deben incluir supuesto, argumento, contraejemplo y evidencia.
