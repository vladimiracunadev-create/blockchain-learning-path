# Registro del estudiante

1. Copia `progress.example.json` con tu nombre.
2. Cambia a `in_progress` al comenzar.
3. Usa `completed` solo con evidencia reproducible.
4. Registra nota 0–100 por módulo.
5. Ejecuta `pnpm course:status ruta/progress.json`.
6. Al terminar las 50 prácticas, módulos y capstone, ejecuta `pnpm course:certificate ruta/progress.json`.

Una evidencia puede ser una ruta a código, prueba, txid local, ADR o informe. Nunca registres claves, seeds, datos personales ni endpoints privados.
