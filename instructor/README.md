# Kit del instructor

## Antes de comenzar

- Ejecuta CI y fija las versiones del semestre.
- Prepara Anvil y Bitcoin regtest sin acceso a fondos reales.
- Aplica diagnóstico y asigna ruta.
- Define canal privado para reportes de seguridad.

## Por clase

1. Expone objetivo observable.
2. Demuestra un caso y un contraejemplo.
3. Hace que el estudiante prediga antes de ejecutar.
4. Exige bitácora, no solo captura.
5. Cierra con un riesgo y una decisión.

## Retroalimentación

Primero corrige modelo mental, después implementación. Un resultado correcto con explicación falsa debe repetirse. En seguridad, separa causa raíz, exploit, impacto, mitigación y riesgo residual.
