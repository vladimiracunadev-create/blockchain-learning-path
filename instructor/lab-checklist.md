# Checklist de laboratorio

- [ ] Red local o testnet confirmada
- [ ] Wallet exclusiva sin fondos reales
- [ ] Versiones registradas
- [ ] Hipótesis escrita antes de ejecutar
- [ ] Comandos reproducibles
- [ ] Resultado esperado y obtenido
- [ ] Pruebas positivas y negativas
- [ ] Amenaza o limitación identificada
- [ ] Evidencia sin secretos ni datos personales
- [ ] Limpieza y cierre de servicios
