# Laboratorio 29 · Exchanges y modelos de custodia

Simula CEX, DEX y el paso de una orden interna a un retiro confirmado. Ejecuta:

```bash
pnpm lab:modelos-custodia
```

No usa red ni claves. La evidencia esperada es una tabla que separa custodia, ejecución, liquidación y estado on-chain/off-chain.
