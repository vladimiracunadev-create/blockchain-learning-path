# Laboratorio 31 · Proof of Reserves y Liabilities

Implementa el flujo `customers → balances → Merkle Tree → root`, prueba inclusión y compara reservas con pasivos.

```bash
pnpm lab:por
```

El resultado es un snapshot pedagógico, no una auditoría financiera. Los nonces, clientes, saldos y wallets son ficticios; no se usan fondos reales.
