# ADR 001 · Blockchain o base de datos

## Contexto

Varios participantes necesitan registrar cambios. Debemos decidir si el costo de consenso compartido está justificado.

## Opciones

- Base central con auditoría.
- Log firmado e inmutable.
- Blockchain permisionada.
- Blockchain pública.

## Criterios

Escritores independientes, autoridad confiable, censura, privacidad, corrección, rendimiento, costo y salida del operador.

## Decisión

Completar para cada proyecto. Si una base tradicional firmada satisface los requisitos, debe preferirse por simplicidad.

## Consecuencias

La elección blockchain añade costos operativos, gestión de claves, finalidad y gobernanza.
