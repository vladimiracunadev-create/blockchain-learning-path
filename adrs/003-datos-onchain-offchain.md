# ADR 003 · Datos on-chain o fuera de cadena

Guarda on-chain solo aquello que otros contratos deben verificar o que requiere disponibilidad consensuada. Usa eventos para historial indexable, almacenamiento direccionado por contenido para artefactos y bases tradicionales para datos privados o mutables. Un hash prueba integridad, no disponibilidad ni veracidad inicial.
