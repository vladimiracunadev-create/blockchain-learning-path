# Proyectos de portafolio

## 1. Explorador conceptual

Analiza bloques y transacciones de una red pública mediante RPC. Entrega diagrama, caché, manejo de errores y límites del proveedor.

## 2. Vault seguro

Amplía el laboratorio con roles, pausa, pruebas fuzz, invariantes, análisis estático y reporte de auditoría.

## 3. DAO comunitaria

Propuesta, voto, quorum, timelock y tesorería multisig en local/testnet. Incluye amenazas de captura.

## 4. Trazabilidad responsable

Prototipo que almacene hashes y eventos, no datos personales. Compara el resultado con una base tradicional firmada.

Cada proyecto debe incluir README, ADR de arquitectura, threat model, pruebas, costos estimados y demo reproducible.
