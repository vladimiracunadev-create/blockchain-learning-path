# Política de seguridad

> [⬅️ Volver al programa](README.md) · [🤝 Contribuir](CONTRIBUTING.md)

Este repositorio es educativo. Los contratos no han sido auditados para producción.

## Reporte responsable

No publiques un exploit activo con fondos en riesgo. **No abras un issue público** con el detalle: escribe de forma privada a **[vladimir.acuna.dev@gmail.com](mailto:vladimir.acuna.dev@gmail.com)** y agrega:

- componente y versión;
- impacto y condiciones;
- pasos mínimos de reproducción;
- posible mitigación.

## Reglas del laboratorio

- Usa Anvil, una red local o testnets.
- Crea wallets exclusivas para aprendizaje.
- No pegues una seed phrase ni una clave privada en código, issues, capturas o IA.
- Verifica red, contrato, función, argumentos, valor y permisos antes de firmar.
- Considera toda entrada externa como hostil.
