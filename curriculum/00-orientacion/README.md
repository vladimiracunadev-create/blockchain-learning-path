# 00 · Orientación

## Objetivos

- Diferenciar blockchain, DLT, criptomoneda y smart contract.
- Reconocer descentralización como un espectro.
- Decidir cuándo no usar blockchain.

## Ideas clave

Una blockchain replica estado entre actores y usa reglas de consenso para aceptar cambios. Su costo adicional solo se justifica cuando varios participantes necesitan coordinarse, no confían en una autoridad única y requieren verificabilidad compartida.

Una base de datos tradicional suele ser mejor si una organización controla escritura, puede corregir datos, exige alta privacidad o necesita gran rendimiento a bajo costo.

## Laboratorio

Evalúa tres casos —registro académico, pagos internacionales y puntos internos de una tienda— con esta matriz:

1. ¿Hay múltiples escritores independientes?
2. ¿Existe una autoridad confiable?
3. ¿Se requiere resistencia a censura?
4. ¿Quién corrige errores?
5. ¿Qué datos jamás deben ser públicos?
6. ¿El beneficio supera costo y complejidad?

## Criterio de salida

Puedes defender una solución blockchain y también rechazarla cuando no aporta valor.
