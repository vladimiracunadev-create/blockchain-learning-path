# 11 · DAO y gobernanza

Estudia propuestas, delegación, quorum, snapshots, voto on-chain/off-chain, tesorería multisig, timelocks y ejecución.

## Amenazas

- compra o préstamo temporal de poder;
- baja participación;
- captura por delegados;
- propuesta maliciosa;
- ejecución inmediata;
- claves administrativas comprometidas.

Diseña una DAO donde una propuesta crítica necesite votación, demora y ejecución verificable. Incluye un mecanismo de emergencia acotado y transparente.
