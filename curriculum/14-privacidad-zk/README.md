# 14 · Privacidad y zero knowledge

Aprende compromiso, witness, circuito, prover, verifier, trusted setup y diferencias generales entre SNARK y STARK.

## Actividad

Diseña una prueba de “soy mayor de 18 años” que no revele fecha de nacimiento. Identifica:

- quién certifica el dato inicial;
- qué información pública recibe el verificador;
- qué metadatos aún filtran información;
- cómo se revoca una credencial.

ZK protege ciertos datos del enunciado, no elimina automáticamente metadatos ni problemas del mundo real.
