# 12 · Escalabilidad y capas 2

Compara canales, sidechains, optimistic rollups, ZK rollups, validiums y appchains.

Evalúa:

- dónde se ejecuta y publica información;
- quién puede secuenciar;
- cómo se prueba un estado inválido;
- disponibilidad de datos;
- tiempo y costo de retiro;
- puentes y mecanismos de escape.

La cifra de transacciones por segundo aislada no representa seguridad ni experiencia completa.
