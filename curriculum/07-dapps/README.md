# 07 · Aplicaciones descentralizadas

Una dApp combina interfaz, proveedor RPC, wallet, contratos, indexación y servicios externos. La interfaz no es una fuente de verdad.

## Temas

- conexión y cambio de red;
- lectura pública vs. escritura firmada;
- simulación antes de enviar;
- estados pending, confirmed, replaced y reverted;
- decimales, unidades, approvals y UX segura;
- RPC no confiable y redundancia.

Construye una interfaz para Vault usando TypeScript y viem. Muestra dirección del contrato, red, valor y efecto esperado antes de pedir firma.
