# 03 · Consenso

Compara Proof of Work, Proof of Stake, BFT y Proof of Authority sin reducir la comparación a energía o velocidad.

| Propiedad | PoW | PoS | BFT/PoA |
|---|---|---|---|
| Recurso anti-Sybil | cómputo/energía | capital bloqueado | identidad/conjunto permitido |
| Finalidad | usualmente probabilística | económica, según protocolo | normalmente rápida |
| Uso típico | red pública abierta | red pública programable | redes pequeñas/permisionadas |

Ejecuta `pnpm lab:pow`, aumenta dificultad y mide intentos y tiempo. El laboratorio es pedagógico; no representa la seguridad real de una red.
