# 08 · Tokens y estándares

Estudia ERC-20, ERC-721, ERC-1155, metadata, allowances, permits, hooks, royalties y account abstraction.

## Proyecto

Implementa un token educativo usando una biblioteca auditada. Documenta:

- autoridad de mint y burn;
- suministro máximo;
- pausa y recuperación;
- riesgo de approvals;
- distribución y concentración;
- razones para que el token exista.

Crear un token técnicamente es fácil; crear utilidad, seguridad y gobernanza responsable es lo difícil.
