# 02 · Sistemas distribuidos y redes P2P

Estudia latencia, particiones, replicación, relojes, tolerancia bizantina, mempool, propagación y Sybil resistance.

## Actividad

Diseña una red de cinco nodos. Simula:

- un nodo desconectado;
- dos mensajes válidos que llegan en distinto orden;
- un nodo malicioso;
- una partición temporal.

Registra qué propiedades priorizas: seguridad, vivacidad, finalidad y disponibilidad.

## Preguntas

1. ¿Por qué “descentralizado” no significa ausencia de gobierno?
2. ¿Cómo se reincorpora un nodo atrasado?
3. ¿Qué diferencia hay entre finalidad probabilística y económica?
