# Diseño pedagógico

## Competencias finales

Al completar el programa, el estudiante puede:

1. decidir justificadamente si un problema necesita blockchain;
2. explicar criptografía, consenso, Bitcoin y EVM con modelos propios;
3. implementar, probar y conectar contratos;
4. descubrir fallos técnicos y económicos;
5. diseñar operación, gobernanza y respuesta ante incidentes;
6. comparar ecosistemas sin depender de marketing;
7. presentar un producto con costos, riesgos y límites explícitos.

## Estructura de una lección

Cada módulo utiliza la plantilla de [curriculum/MODULE_TEMPLATE.md](../curriculum/MODULE_TEMPLATE.md):

- diagnóstico breve;
- explicación y demostración;
- práctica guiada;
- reto independiente;
- reflexión y bitácora;
- prueba automática o rúbrica;
- criterio de dominio.

## Taxonomía de evidencias

| Nivel | Verbo observable | Evidencia |
|---|---|---|
| Recordar | identificar | cuestionario |
| Comprender | explicar | nota técnica |
| Aplicar | ejecutar | laboratorio |
| Analizar | comparar | ADR o matriz |
| Evaluar | auditar | informe |
| Crear | diseñar | proyecto final |

La aprobación no depende solo de compilar. El estudiante debe justificar decisiones, identificar riesgos y reproducir resultados.
