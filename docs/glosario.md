# Glosario esencial

| Término | Significado |
|---|---|
| ABI | Especificación para codificar llamadas y respuestas de contratos EVM |
| Bloque | Conjunto ordenado de transacciones y metadatos enlazado criptográficamente |
| Consenso | Reglas para acordar el estado válido entre participantes |
| Gas | Unidad que mide trabajo computacional en EVM |
| Hash | Huella determinista de longitud fija |
| L1 / L2 | Capa base / sistema que escala apoyándose en una capa base |
| Merkle tree | Estructura que permite probar inclusión eficientemente |
| Nodo | Software que valida, almacena o comunica datos de la red |
| Nonce | Valor usado una vez; su función depende del protocolo |
| Oráculo | Mecanismo que lleva datos externos al entorno on-chain |
| Rollup | L2 que agrupa ejecución y publica datos o pruebas en una L1 |
| Smart contract | Programa determinista ejecutado por una red |
| UTXO | Salida de transacción no gastada, base del modelo de Bitcoin |
| Wallet | Herramienta que administra claves y firma; no “guarda monedas” literalmente |
| ZK proof | Prueba criptográfica de una afirmación sin revelar todos los datos |
