# Proyecto final

Construye un protocolo pequeño que resuelva un problema real y permita demostrar dominio integral.

## Entregables

- problema, usuarios y criterios de éxito;
- ADR: por qué blockchain y qué alternativa se descartó;
- arquitectura y límites de confianza;
- contratos con NatSpec;
- interfaz accesible;
- pruebas unitarias, integración, fuzz e invariantes;
- análisis estático e informe de auditoría;
- modelo de amenazas y plan de incidentes;
- script de despliegue local/testnet;
- estimación de gas y operación;
- demo y defensa de 10 minutos.

## Puertas de calidad

No se aprueba si usa fondos reales, expone secretos, oculta privilegios administrativos o carece de pruebas para invariantes críticas.
